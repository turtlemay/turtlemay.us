## Other hardware

**Mechanical keyboards**[^mechanical-keyboards]
- Keycool K84 bluetooth with brown switches (discontinued)
- [DREVO Gramr 84-key backlit](https://www.drevo.net/product/keyboard/gramr)

with no number pad. Keeps the mouse hand closer to home.

but didn't find it worth the real estate compared to software macros.

**Backup & Sync**
- [Syncthing](https://syncthing.net/)
	for LAN file sync and backup.
	Syncs my Android camera roll, password databases, notes,
	scripts, configs/save files, and project files.
- [Bvckup 2](https://bvckup2.com/)
	for Windows backup to home
	[samba](https://www.samba.org/)
	server
- [rsync](https://en.wikipedia.org/wiki/Rsync)
	with [bash](https://en.wikipedia.org/wiki/Bash_(Unix_shell))
	scripts and [cron](https://en.wikipedia.org/wiki/Cron)
	for linux backup to NAS via
	[sshfs](https://github.com/libfuse/sshfs)
