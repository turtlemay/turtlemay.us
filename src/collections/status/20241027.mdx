New blog/website launched at https://www.turtlemay.us/. This is the first personal site I've had in quite a few years and I expect will contain some tech-related articles, photography, and links to my various projects.

So far it's a pure static build using the [Astro](https://astro.build/) framework, which I'm quite happy with. Single-file UI components with backend scripting feels so much like the PHP days but with fancy compile-time capabilities, hot-reloading, and the option to hydrate client-side UI. It's the convenient workflow I've been sorely missing through a decade of Express.js and the like.
